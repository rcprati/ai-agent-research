# Cases to practice reviewing

Five folders with **wrong results**: four from Lesson 1 (produced in Antigravity) and `caso-4-eos` (produced in OpenWork). Each has `resposta_do_autor.md` (the author's answer, in Portuguese), `script_do_autor.py`, and the data. The data are synthetic; file names and comments are in Portuguese.

## Request to the reviewer (no skill)

> You are an independent reviewer. An author produced the result described in resposta_do_autor.md, with the script script_do_autor.py and the files in this folder. Review this result critically. Say whether you trust it and why, with evidence, and what value or conclusion you obtained independently. Do not change the author's files.

## With the skill

Install `review-result` (or ask it to follow the `SKILL.md`) and use the same request in a fresh session.

The answer keys for cases 1 to 3B are in the Lesson 1 material ("Answer keys"); the one for case 4 is in the "Case 4 answer key" download. Each author's answer was reassembled from what it returned.

## Case 4 (equation of state of Cu and Al)

The reference values come from the Delta test (Lejaeghere et al., 2014; see the answer key); we reconstructed the energies ourselves, they are not DFT output. The folder also has `pedidos.md`, with the restricted and the rewritten request (in Portuguese), to run in your own agent (in copies without `resposta_do_autor.md` and `script_do_autor.py`).
