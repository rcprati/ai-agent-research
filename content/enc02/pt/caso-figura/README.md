# Caso da figura (dados sintéticos)

`dados_eos.csv`: energia total (eV/átomo) em função do parâmetro de rede (Å) para dois funcionais (PBE e PBE+D3).

## Prompt (o mesmo sem e com o skill)

> Crie um script em python que faça uma figura da energia versus o parâmetro de rede, com os dois funcionais, a partir de dados_eos.csv, com os rótulos em inglês

Com o skill: instale-o na ferramenta (ou peça para seguir o `SKILL.md`) e use o mesmo prompt em sessão nova.
